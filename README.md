# UGS Travels (mock)

A mock marketing site for a travel agency. It presents visa assistance, flight booking, hotel reservations and tour packages, with a WhatsApp call-to-action for enquiries.

## Sections

- Hero with call-to-action
- Services: visa assistance, flight booking, hotel reservations, tour packages
- Destination cards for 16 countries (United States, United Kingdom, Canada, Australia, UAE, Malaysia, Thailand, Singapore, Turkey, Saudi Arabia, Japan, South Korea, Maldives, Italy, France, Switzerland)
- Contact links (WhatsApp, email, phone) and social links
- `sitemap.ts` for SEO

This is a design mock. Contact details and photos are placeholders.

## Tech stack

Next.js (App Router), React, TypeScript

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
```

| Script | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm start` | Run the production build |
| `npm run lint` | Lint with ESLint |
